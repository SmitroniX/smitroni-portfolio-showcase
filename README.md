## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Visit `http://localhost:5173` in your browser.

### 3. Build for Production
```bash
npm run build
```
Production assets will be emitted to `dist/`.

### 4. Preview Production Build
```bash
npm run preview
```

---

## 🌐 One-Click Deploy

- **Vercel**: Import repository -> Framework: Vite -> Root Directory: `./` -> Deploy!
- **Netlify**: Build command: `npm run build` -> Publish directory: `dist` -> Deploy!
- **GitHub Pages**: Build and push the `dist/` directory or use GitHub Actions.
