## ✨ Features & Design System

- **Bento Grid Architecture**: Clean, modular layout inspired by Linear, Raycast, and modern design systems.
- **Spotlight Hover Physics**: Dynamic mouse-following radial highlights on card borders and surfaces.
- **Ambient 3D Particle Field**: Subtle, organic WebGL Three.js background reacting gently to cursor motion.
- **Interactive Product Mocks**: Tabbed interactive browser frames displaying realistic UI previews of **DYPU Connect**, **AniDex & AniPlex**, **Shadow_API**, and **Gemini CLI**.
- **Linear-Style Command Palette (`⌘K`)**: Fast keyboard navigation to jump between projects, copy email, or explore social profiles.
- **Live Mumbai Clock**: Real-time timezone counter with IST time.
- **Authentic Career & Education Timeline**: Naviotech Solutions internship, Social Wing RAIT leadership, and Hypixel systems work.
- **Web Audio Micro-interactions**: Pure Web Audio API synthesizer for tactile clicks and hovers with a clean mute toggle.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/SmitroniX/smitroni-portfolio-showcase.git
cd smitroni-portfolio-showcase

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
